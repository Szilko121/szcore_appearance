# szcore_appearance

SzCore v1.4.0-rc1 character appearance system.

Includes a native character studio, live camera preview, freemode male/female models, head blend, face features, overlays, hair, clothing/props and persistent wardrobe/outfits.

Dependencies: `oxmysql`, `szcore`, `szcore_ui`.

Public exports:
- client: `ApplyAppearance`, `SaveAppearance`, `OpenCreator`
- server: `GetAppearance`, `SaveAppearance`, `GetOutfits`, `SaveOutfit`, `DeleteOutfit`
